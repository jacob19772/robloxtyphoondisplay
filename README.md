# RAF Typhoon Display Team — GitHub Pages website (fixed edition)

## Fix for missing colours, layout and images

This package has the CSS, Javascript and the original two supplied logos EMBEDDED in each HTML page. That means a missing `assets` folder cannot break the look of the site. The `assets` folder is also included as editable source material.

## How to publish correctly

1. Extract the ZIP onto your computer. Do not upload the ZIP itself.
2. Open your public GitHub repository.
3. Select **Add file → Upload files** and drag in **everything INSIDE** the extracted folder, including the `about-us`, `gallery`, `events`, `faq`, `contact-us` and `apply` folders, plus `index.html`, `404.html`, and `assets`.
4. If you are replacing an earlier version, overwrite the corresponding files and commit the changes. On GitHub's website, uploading a folder by dragging the folder into the upload area may preserve its structure; always check it after upload.
5. Under **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
6. Allow GitHub Pages to publish. If you still see the old website, use **Ctrl+F5** to reload. Pages must be accessible at `/about-us/`, `/gallery/`, etc.
7. Confirm `index.html` appears in the repository root (NOT inside another folder called `raf-typhoon-github-fixed`).

You can open `index.html` directly in a browser to see the styling. Links between subfolders work reliably when hosted via GitHub Pages.

## Website content

Seven pages: Home, About us, Gallery, Events, FAQ, Contact and Apply. Responsive design, gallery modal, FAQ accordion, and local-draft forms.

Forms do NOT automatically deliver data to anyone. They store drafts only in the visitor's browser. To receive messages/applications, set up a separate form-delivery service.
